EN - Inventory Simple Manager

Inventory Simple Manager (ISM) its a simple tool to help you manage your business inventory faster and easly.

REQUERIMENTS:
- Have python 3.6 or an newer version installed in your device
- A terminal to run the program
- It don't needs external libraries

INSTRUCTIONS
 1. Save the .py archive in a folder
 2. Open a terminar in the folder of the archive
 3. Execute this command: python name.py (replace name with the name of your archive)

HOW TO USE
 1. When you execute the command you are going to see this menu

   Welcome to you Inventory Simple Manager
   1. Register a product and its available quantity
   2. Show all products with their quantities.
   3. Search for a product by name.
   4. Change the available quantity of a product.
   5. Remove a product from inventory.
   6. Show how many different products are registered.
   7. Display the product with the largest or smallest available quantity.
   0. Exit menu

2. Type the number with the option you want.
3. The program is going to ask you some confirmation inputs, use press [y] to say "yes" and [n] to say "no".
4. When you finish an action press [enter] to go back to the main menu.
5. If you want to exit just press [0].

IMPLEMENTED FUNCTIONS

ShowMenu() To show the main menu
SelectOption() To select an option of the menu
returnMenu() To go back to the main menu
OptionNumber() Executes the action of the option that yo choose previously

WARININGS
- Your data doen't save when you stop the porgram, this is a 1 sesion program.
- Be carefull with the names of your products, try to put the names without upper keys
- If you put a text in an number input the program is going to stop with an error, be carefull with this.
- You moust be have at least one product registered to use the program without errors.

ES - Inventory Simple Manager

Inventory Simple Manager (ISM) es una herramienta sencilla que te ayuda a gestionar el inventario de tu negocio de forma rápida y fácil.

REQUISITOS:
- Tener instalado Python 3.6 o una versión más reciente en tu dispositivo
- Un terminal para ejecutar el programa
- No necesita bibliotecas externas

INSTRUCCIONES
 1. Guarda el archivo .py en una carpeta
 2. Abre un terminal en la carpeta donde se encuentra el archivo
 3. Ejecuta este comando: python nombre.py (cambia la palabra nombre con el nombre del archivo)

CÓMO UTILIZARLO
 1. Al ejecutar el comando, verás este menú

   Bienvenido a tu Gestor de inventario
   1. Registra un producto y su cantidad disponible
   2. Mostrar todos los productos con sus cantidades.
   3. Buscar un producto por nombre.
   4. Modificar la cantidad disponible de un producto.
   5. Eliminar un producto del inventario.
   6. Mostrar cuántos productos diferentes hay registrados.
   7. Mostrar el producto con la mayor o la menor cantidad disponible.
   0. Salir del menú

2. Introduce el número correspondiente a la opción que desees.
3. El programa te pedirá algunas confirmaciones; pulsa [y] para decir «sí» y [n] para decir «no».
4. Cuando termines una acción, pulsa [Intro] para volver al menú principal.
5. Si quieres salir, solo tienes que pulsar [0].

FUNCIONES IMPLEMENTADAS
ShowMenu() Para mostrar el menú principal
SelectOption() Para seleccionar una opción del menú
returnMenu() Para volver al menú principal
OptionNumber() Ejecuta la acción de la opción que hayas elegido previamente

ADVERTENCIAS
- Tus datos no se guardan al cerrar el programa; se trata de un programa de una sola sesión.
- Ten cuidado con los nombres de tus productos; intenta escribirlos sin mayúsculas.
- Si introduces texto en un campo numérico, el programa se detendrá con un error; ten cuidado con esto.
- Debes de tener al menos un dato registrado para poder usar el programa sin errores
